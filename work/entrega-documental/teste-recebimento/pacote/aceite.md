# Aceite

Versão candidata: D003

| Campo | Valor |
| --- | --- |
| Decisão | pendente |
| Versão recebida | não registrada |
| Nome de quem decide | não registrado |
| Data | não registrada |
| Lista de correções | não registrada |

Enquanto a decisão estiver pendente, não há aceite. Ausência de resposta não
é aceite. O aceite registra o recebimento conforme os critérios combinados; não
significa concordância com a veracidade das fontes.
