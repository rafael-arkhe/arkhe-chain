## Como ler

| Arquivo | Conteúdo |
| --- | --- |
| `indice.md` | IDs, nomes recebidos, versões e origens declaradas, relação |
| `originais/` | Cópias exatas dos arquivos aceitos, uma pasta por ID |
| `somas.sha256` | SHA-256 de cada original, para detectar diferença de cópias |
| `referencias.md` | Afirmações selecionadas, onde estão, qual fonte as apoia |
| `alteracoes.md` | Diferença linha a linha entre versões e campos alterados |
| `pendencias.md` | Lacunas, efeito, responsável proposto, condição de fechamento |
| `ocorrencias.md` | Conteúdo registrado no recebimento, texto com cara de instrução |
| `relatorio.md` | Resultado da conferência e alcance da revisão |
| `aceite.md` | Decisão do cliente; inicialmente pendente |
| `extracoes/` | Texto extraído dos PDFs, para localizar trecho e página. Não substitui o original |

Todos os caminhos são relativos a esta pasta. O pacote é texto simples: abre em
qualquer editor, sem rede, sem conta e sem serviço Arkhe.

Os endereços de PDF citam a página física do arquivo. A extração em
`extracoes/` é arquivo de trabalho: se um trecho citado ficar ambíguo, confira
no original em `originais/`.

## Limites

- A soma de verificação detecta diferença entre duas cópias. Não autentica a
  origem: quem substituir arquivo e soma ao mesmo tempo oculta a alteração.
  Mantenha sua própria cópia de referência do que enviou.
- Não há assinatura digital nem carimbo temporal neste pacote.
- Nomes, versões e origens são declarações de quem enviou, não verificadas.
- O conteúdo das fontes foi tratado como dado. Nada nele foi executado.
