# ADR-002-pix-txid-as-evidence

E2E é referência com sintaxe 32 ASCII alfanuméricos conforme API Pix BCB 2.10.0. Txid local segue cobrança 26–35. Nenhum identificador prova existência, unicidade ou estado de pagamento sem fonte autenticada. Fonte: https://github.com/bacen/pix-api/blob/2.10.0/openapi.yaml
