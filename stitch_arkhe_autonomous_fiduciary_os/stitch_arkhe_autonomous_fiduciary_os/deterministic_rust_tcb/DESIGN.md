## Brand & Style

This design system embodies the rigorous determinism, mathematical verifiability, and absolute integrity demanded by a mission-critical computational fiduciary layer and autonomous operating runtime. Designed explicitly for systems engineers, cryptographic auditors, and security architects, the visual language avoids decorative fluff in favor of high-density clarity, structural alignment, and sovereign execution transparency.

The aesthetic fuses **Modern Technical Architecture** with **Engineered Brutalism**:
- **Absolute Precision**: Layouts reflect formal machine interfaces, micro-benchmarks, and kernel-level tracing rather than consumer application fluff.
- **Fail-Closed Semantics**: Every state transition, cryptographic assertion, and capability grant is visually definitive; ambiguous UI states do not exist.
- **Cryptographic Grounding**: Typography and spatial metrics optimize for continuous scanning of 256-bit hashes, zero-knowledge proofs, system capability manifests, and Rust memory-layout diagrams.
- **Instrument-Grade Restraint**: Contrast ratios exceed enterprise accessibility benchmarks, pairing cold deep-obsidian baseplates with razor-sharp slate structural vectors and deterministic signal states.

## Colors

The color palette is engineered specifically for sustained optical performance under dense data loads, using strict functional semantic mapping:

### Background Architecture & Structural Tiers
- **Canvas Base (Deep Obsidian)**: `#0A0D12` — Primary non-emissive backdrop; eliminates screen glare and establishes terminal-grade depth.
- **Surface Elevation 1 (Engine Bed)**: `#0E131B` — Primary container background for operational panels, memory maps, and execution tables.
- **Surface Elevation 2 (Active Core)**: `#151C28` — Secondary interactive surfaces, toolbars, modal headers, and raised telemetry cards.
- **Surface Elevation 3 (Focused State)**: `#1B2434` — Hover states, code line active highlights, and active breadcrumbs.
- **Structural Boundaries (Slate Wire)**: `#243044` — 1px deterministic dividers, matrix grids, and bounding boxes.
- **Subtle Partition**: `#1A2332` — Micro-borders for secondary structural tables and internal splitters.

### Deterministic State Signals
- **Primary / Verified Attestation (Emerald Deterministic)**: `#10B981` — Validated cryptographic proofs, green-lit capability grants, operational health, and verified BLAKE3 hashes.
- **Secondary / Kernel Subsystem (Cyber Blue)**: `#38BDF8` — Runtime primitives, active execution threads, memory pointers, Rust traits, and syscall triggers.
- **Tertiary / Audit Telemetry (Audit Amber)**: `#F59E0B` — Memory pressure, uncommitted fiduciary proposals, audit warnings, and non-blocking invariant cautions.
- **Critical Failure / Fail-Closed (Crimson Denied)**: `#EF4444` — Proof failure, capability revocation, untrusted environment assertion, and memory violations.

### Monochromatic Text & Readability Tiers
- **Text Ultra-High (Primary Metric)**: `#F1F5F9` — Spec titles, hash values, execution metrics, and active syntax tokens.
- **Text Balanced (Functional Data)**: `#94A3B8` — Table rows, body specifications, and architectural documentation.
- **Text Low-Contrast (Metadata / Timestamps)**: `#64748B` — Memory offsets, invariant keys, line numbers, and deactivated states.

## Typography

The typographic hierarchy prioritizes technical legibility, optical differentiation of cryptographic strings, and structural scanning speed under operational tension.

- **Dual-Engine Type System**:
  - **Interface & Prose (`Inter`)**: Engineered for tabular clarity, crisp legibility at small sizes, and neutral rendering of technical prose. Figures must use tabular formatting (`font-variant-numeric: tabular-nums`) by default across all dashboards.
  - **Runtime & Contracts (`JetBrains Mono`)**: Applied to all cryptographic hashes, memory addresses, byte offsets, Rust code snippets, capability matrices, and audit logs. Ensures unambiguous differentiation between `0` and `O`, `1` and `l`, and invariant indicators.
- **Typographic Rules**:
  - `label-caps` must strictly be set in `text-transform: uppercase` with deliberate micro-letter-spacing (`0.08em`) for hardware-inspired panel markings (e.g., `TCB_STATUS`, `HASH_VERIFIED`, `RING_0`).
  - Cryptographic values (e.g., BLAKE3 digests) must never wrap mid-character; they must render in `code-sm` or `code-md` inside scrollable or truncated single-line containers with copy-on-click telemetry.

## Layout & Spacing

The layout is built around high-density engineering workspaces, structural data docking, and interactive reference splitters:

- **Structural Grid Strategy**:
  - **Desktop (>= 1280px)**: 12-column or 16-column continuous fluid workbench. Standard gutter of `1.5rem` (`24px`) and canvas margin of `2rem` (`32px`). Multi-pane docking architectures: Navigation Tree (240px fixed), Primary Engineering Workspace (fluid), and Real-Time Verification Telemetry Rail (320px fixed).
  - **Tablet (768px – 1279px)**: 8-column layout with `1rem` (`16px`) gutters and margins. Telemetry rails collapse into bottom drawers or contextual sidebars.
  - **Mobile (< 768px)**: 4-column layout with `1rem` margin. Panes stack strictly top-to-bottom: System Status Banner -> Primary Workspace -> Event Log Stream.
- **Information Density Rhythm**:
  - Spacing follows a modular 4px base (`0.25rem`). Critical tabular data and diagnostic terminals use condensed paddings (`space-xs` and `space-sm`) to maximize visible context without vertical displacement.
  - Section-level separations maintain strict mathematical rhythm (`space-lg` to `space-2xl`) using 1px slate structural dividers rather than large swathes of empty negative space.

## Elevation & Depth

This design system avoids blurry drop-shadows and skeuomorphic lighting in favor of **Crisp Architectural Layering** and **Luminescent Border Highlights**:

- **Layer 0 (Base Canvas - `#0A0D12`)**: The unmovable kernel baseline. No borders, pure absorption.
- **Layer 1 (Recessed/Embedded Wells - `#080A0E`)**: Inner viewports, code editors, terminal output, and log streaming consoles. Outlined with `1px solid #1A2332` with an inset shadow (`inset 0 1px 2px rgba(0, 0, 0, 0.6)`).
- **Layer 2 (Primary Structures - `#0E131B`)**: Architectural cards, data tables, and tree diagrams. Framed with a precise `1px solid #243044` border. No drop shadow.
- **Layer 3 (Active Overlays & Modals - `#151C28`)**: Context menus, cryptographic sign-off dialogs, and capability selectors. Bordered with `1px solid #38BDF8` (at 40% alpha) and elevated using a deep directional shadow: `0 8px 32px -4px rgba(0, 0, 0, 0.8)`.
- **Luminescent Accent Strokes**: Interactive cards in hover or active execution states gain an inner glow effect via `box-shadow: inset 0 0 0 1px rgba(16, 185, 129, 0.2)` or `rgba(56, 189, 248, 0.2)` rather than outward diffusion.

## Shapes

The shape grammar is calibrated for **Industrial Precision** (`roundedness: 1` — Soft / Ultra-compact corner radii):

- **Corner Radii Rules**:
  - `rounded-none` (`0px`): Outer console frames, code editor containers, data table headers, and split-pane dividers.
  - `rounded-sm` (`2px` / `0.125rem`): Inline badges, code blocks, hash chips, progress segments, and micro-steppers.
  - `rounded-md` (`4px` / `0.25rem`): Standard interactive targets including buttons, input fields, dropdown menus, and card perimeters.
  - `rounded-lg` (`8px` / `0.5rem`): Dialog viewports and isolated system modals.
  - Continuous circular geometries (`9999px`) are strictly forbidden, with the single exception of status beacon pulse dots (`6px` or `8px` indicators).

## Components

### Buttons & Cryptographic Actuators
- **Primary / Authorize**: Solid `#10B981` with `#0A0D12` text in `Inter` Medium (`14px`). Hover transitions to `#059669`. Focused state triggers a `2px solid rgba(16, 185, 129, 0.4)` offset ring.
- **Secondary / Syscall**: Background `#151C28`, border `1px solid #243044`, text `#38BDF8`. Hover updates border to `#38BDF8` and background to `#1B2434`.
- **Fail-Closed / Revoke**: Background `rgba(239, 68, 68, 0.1)`, border `1px solid rgba(239, 68, 68, 0.4)`, text `#EF4444`. Hover switches to solid `#EF4444` with `#0A0D12` text.
- **Button Sizing**: Compact height (`32px` standard, `26px` dense) to retain terminal efficiency.

### Input Fields & Parameter Consoles
- **Base Style**: Background `#080A0E`, border `1px solid #243044`, text `#F1F5F9` in `JetBrains Mono` (`13px`).
- **Focus**: Border switches cleanly to `#38BDF8` with a subtle `box-shadow: 0 0 0 1px #38BDF8`. No default browser glow.
- **Validation Indicators**: An immutable right-hand indicator showing BLAKE3 validation checkmark (`#10B981`) or invalid capability state (`#EF4444`).

### Chips, Badges & Cryptographic Tags
- **Hash / Capability Chip**: Mono font (`code-sm`), background `#0E131B`, border `1px solid #243044`, text `#94A3B8`. Displays a prefix icon (e.g., key, shield) and appends a copy icon on mouse hover.
- **State Badges**:
  - `VERIFIED`: Background `rgba(16, 185, 129, 0.1)`, border `rgba(16, 185, 129, 0.3)`, text `#10B981`.
  - `KERNEL_EXEC`: Background `rgba(56, 189, 248, 0.1)`, border `rgba(56, 189, 248, 0.3)`, text `#38BDF8`.
  - `AUDIT_HOLD`: Background `rgba(245, 158, 11, 0.1)`, border `rgba(245, 158, 11, 0.3)`, text `#F59E0B`.
  - `FAIL_CLOSED`: Background `rgba(239, 68, 68, 0.1)`, border `rgba(239, 68, 68, 0.3)`, text `#EF4444`.

### Data Tables & Invariant Matrices
- **Table Headers**: Background `#0E131B`, text `label-caps` in `#64748B`, border-bottom `1px solid #243044`, height `32px`.
- **Table Rows**: Monospace values formatted with `tabular-nums`. Height `36px`. Zebra striping avoided; row separation handled strictly via `1px solid #1A2332`. Hover state highlights full row in `#151C28`.

### Specialized Domain Components
- **BLAKE3 Hash Inspector**: Dual-segment inline atom. Left segment holds the algorithm label `B3` in `#38BDF8` on `#080A0E`; right segment displays truncated digest `7a1f…c84e` in `#F1F5F9`. Hover expands to full 64-character hex with verification tooltip.
- **TCB State Ledger**: Real-time event log featuring micro-status indicators (flashing green beacon for deterministic tick sync), monotonic counter offsets, and isolated Rust error traces rendered with colored syntax highlighting.
- **Capability Access Matrix**: Split-grid card showing caller identity, memory page permissions (`r-x`, `rw-`, `---`), and zero-knowledge validity attestations enclosed in slate framing.
