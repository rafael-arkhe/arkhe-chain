REGRA #01 sort_by_alpha

Ordenação Lexicográfica Canônica

Mapas e pares de chaves estruturais são ordenados byte-a-byte estritamente pelo comprimento da chave e valor numérico (RFC 8949 §4.2.1). Qualquer mapa fora de sequência é rejeitado no byte 0.

REGRA #02 compress

Inteiros de Tamanho Mínimo

Proibição estrita de padding artificial. Inteiros em 0..23 ocupam 1 byte. 24..255 são codificados exclusivamente como 0x18 + valor. Desvios acionam falha de validação imediata.

REGRA #03 cancel

Proibição de Undefined & Floats NaN

Valores de ponto flutuante NaN, subnormais, infinitos e tipos CBOR undefined (0xf7) provocam rejeição Fail-Closed no deserializador nativo. TCB opera exclusivamente em ponto fixo e inteiros.

//! ARKHE PROTOCOL: TCB Canônico AKG-CBOR-v1
#![no_std]
extern crate alloc;
use alloc::{string::String, vec::Vec};
use serde::{Deserialize, Serialize};
use blake3::Hasher;

/// Domain Separation Constants para Prevenção de Ataques Cross-Type
pub const DOMAIN_OPERATION_V1: &[u8] = b"arkhe:operation:v1";
pub const DOMAIN_INTENT_V1: &[u8]    = b"arkhe:intent:v1";

#[derive(Clone, Copy, Debug, PartialEq, Eq, PartialOrd, Ord, Hash, Serialize, Deserialize)]
#[repr(transparent)]
pub struct ContentHash(pub [u8; 32]);

#[derive(Clone, Debug, PartialEq, Eq, PartialOrd, Ord, Serialize, Deserialize)]
#[serde(rename_all = "snake_case")]
pub struct WorkIntent {
    /// Chaves com ordenação canônica estrita (RFC 8949 §4.2.1)
    pub context: Vec<ContentHash>,
    pub created_at: u64,
    pub intent_type: String,
    pub parameters: Vec<u8>,
    pub request_identity: ContentHash,
    pub requested_by: String,
    pub target: ContentHash,
}

impl WorkIntent {
    /// Serialização Canônica Determinística AKG-CBOR-v1
    pub fn to_canonical_cbor(&self) -> Result<Vec<u8>, serde_cbor::Error> {
        let mut buffer = Vec::new();
        let mut serializer = serde_cbor::Serializer::new(&mut buffer);
        // Ativa regras de determinismo estrito (RFC 8949 §4.2.1)
        serializer.packed_format();
        self.serialize(&mut serializer)?;
        Ok(buffer)
    }

    /// Cálculo Criptográfico de Identidade da Operação
    pub fn operation_id(&self) -> ContentHash {
        let mut hasher = Hasher::new();
        hasher.update(DOMAIN_OPERATION_V1);
        hasher.update(self.intent_type.as_bytes());
        hasher.update(&self.target.0);
        hasher.update(&self.request_identity.0);
        
        let result = hasher.finalize();
        ContentHash(*result.as_bytes())
    }

    /// Digest Integral da Intenção para Registro no Ledger TCB
    pub fn intent_digest(&self) -> ContentHash {
        let cbor_bytes = self.to_canonical_cbor().expect("Deterministic serialize");
        let mut hasher = Hasher::new();
        hasher.update(DOMAIN_INTENT_V1);
        hasher.update(&cbor_bytes);
        ContentHash(*hasher.finalize().as_bytes())
    }
}
