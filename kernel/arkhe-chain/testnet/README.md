# Local testnet (scaffolding)

Operational material lives in `local/` (gitignored). Guide: [docs/testnet.md](../docs/testnet.md).

Scripts: `gen-keys`, `init-local`, `start-node`, `collect-peers`, `write-peers-docker`, `faucet-tx`, `send-attest`, `check-status`, `run-local`, `run-background` / `stop-background`, `smoke-local`, `clean-local`.

This does **not** homologate the chain and is **not** a public network. Keys never enter git.
