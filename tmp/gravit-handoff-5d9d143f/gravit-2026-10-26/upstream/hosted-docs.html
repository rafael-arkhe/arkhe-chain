1. Decide an artifact

curl https://gravitverifier.space/api/v1/verify \
  -H "Authorization: Bearer $GRAVIT_API_KEY" -H "Content-Type: application/json" \
  -d '{"artifact": {"artifact_id": "payment-4711", "claimed_state": "Verified Fact",
       "context": {"evaluation_time": "2026-10-13T12:00:00Z", "freshness_max_age_seconds": 300},
       "evidence": [ ...signed evidence records... ]}}'

The response contains result.decision (state, status, reason, decision_id), result.explanation (rules and revisions applied, what independence rests on), result.graviteron, and the receipt with its signature.

Graviteron next to the decision says how strongly the counted evidence supports the claim (expected, from 0 to 1) and how much evidence stands behind it (uncertainty; 1 means none). Keys of one operator count as one source. For now every operator is trusted equally, so the calibration of this number is not yet established; the decision itself does not depend on it. Method: evidence-measure.md.

2. Python

pip install "git+https://github.com/gravit-open-network-foundation/gravit-verifier-service#subdirectory=sdk/python"

from gravit_verifier_client import Client, verify_response, verify_export
gv = Client("gv_...")
res = gv.verify(artifact)
print(res["result"]["decision"]["final_epistemic_state"])

key = gv.service_key()                       # pin it once
print(verify_response(res, key, artifact))   # signature, result hash, request hash
print(verify_export(gv.export(), key))       # every receipt signed, chain unbroken

3. TypeScript

import { Client } from "gravit-verifier-client";   // source: sdk/typescript in the repository
const gv = new Client(process.env.GRAVIT_API_KEY);
const res = await gv.verify(artifact);
console.log(res.result.decision.final_epistemic_state, res.result.decision.status);

Capability Gate

For AI agents: list what is allowed, what is on the frontier and needs proof, and what is forbidden. Anything not listed is unknown and blocked. A frontier capability is permitted for one action only, when you pass the decision_id of a Verified Fact from /verify whose artifact_id is that action's hash.

g = gv.gate("pay", {"revision": "r1", "allowed": ["read"], "frontier": ["pay"], "forbidden": ["wipe"]},
            action={"to": "acct_42", "amount": 250})
h = g["result"]["gate"]["action_hash"]      # use as artifact_id when you verify the evidence
res = gv.verify({"artifact_id": h, "claimed_state": "Verified Fact", "evidence": [...]})
g = gv.gate("pay", policy, action={"to": "acct_42", "amount": 250}, decision_id=res["receipt"]["decision_id"])
print(g["result"]["gate"]["permitted"])     # True only for a Verified Fact about this exact action

Specification and tests: capability-gate.

Receipts you can check yourself

  • The service passes your request to the verifier byte for byte, so signed numbers keep their exact form; request_sha256 records what was decided.
  • result_sha256 covers the exact result you received. The service signs the receipt with Ed25519.
  • Each receipt names the hash of the one before it. Removing or changing any entry later breaks the chain, and verify_export reports it.
  • The decision itself is reproducible: run the same artifact through the open source verifier at the same version and you get the same decision_id.
