# security-app

Painel operacional de segurança pública. Único locale: pt-BR.

## Desenvolvimento

```bash
npm install --legacy-peer-deps
cp .env.example .env.local
npm run dev    # http://localhost:3002
```

## Testes

```bash
npm test                 # unit (Jest)
npm run test:e2e         # e2e (Playwright)
```
