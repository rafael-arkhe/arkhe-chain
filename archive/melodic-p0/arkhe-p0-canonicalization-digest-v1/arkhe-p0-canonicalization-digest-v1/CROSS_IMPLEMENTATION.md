# Cross-Implementation Gate

## Current direction

The checked-in vectors are generated by:

`reference/python/arkhe_p0_ref.py`

That implementation manually encodes the restricted deterministic-CBOR profile and uses Python's standard SHA-256 implementation.

Rust must reproduce:
- canonical CBOR bytes;
- SHA-256 of exact canonical bytes;
- domain/profile-bound structured SHA-256.

## Required before public wire freeze

1. Python -> Rust parity.
2. Rust -> second independent implementation parity.
3. Differential tests against a mature RFC 8949 implementation.
4. Negative vectors:
   - duplicate keys;
   - unsupported/unknown algorithm IDs;
   - indefinite-length encodings;
   - non-shortest integer encodings;
   - floats/tags outside the profile;
   - malformed UTF-8 on decode.
5. Fuzzing/property tests for deterministic round trips.

The rule is:

`same semantic Arkhe object => same canonical bytes`

and not merely:

`two implementations happened to agree on the happy path`.
