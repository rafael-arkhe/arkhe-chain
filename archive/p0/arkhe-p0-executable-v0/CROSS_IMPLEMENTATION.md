# Cross-implementation gate

The Rust implementation and `reference/canonical_ref.py` are intentionally independent implementations of the same restricted canonical profile.

The reference implementation uses no CBOR package and emits the required subset manually. The vectors in `vectors/p0-v0.json` were generated by the reference implementation, not by the Rust crate.

Required CI gate once Rust is available:

1. Run the Python reference vector generator.
2. Run Rust golden-vector tests against those bytes.
3. Add a second decoder/verifier implementation before declaring wire compatibility stable.
4. Any mismatch is fail-closed and blocks release.

Agreement is necessary but not sufficient for correctness; vectors should also be reviewed against an external deterministic-CBOR implementation and RFC 8949 encoding rules before v1 freeze.
