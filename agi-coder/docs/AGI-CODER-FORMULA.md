# The AGI Coder formula

The source document proposes:

**AGI Coder = Frontier Coding Agent + Autonomous Verification + Long-Horizon Planning + Cryptographic Accountability.**

This is a decomposition of engineering responsibilities, not a theorem about general intelligence. An accountability kernel can bind records and constrain actions without supplying reasoning ability. A strong coding model does not eliminate the need for independent verification, durable state, and trusted authorization.

This implementation supplies a provider client and worker interfaces; independent finite-domain and process mutation verification; deterministic dependency planning with bounded retries; inspectable memory and sourced research contracts; and signed, evidence-gated execution with portable MMR proofs. It does not train or supply a frontier model, autonomously discover requirements, prove arbitrary code correct, or establish demand autonomy.

The numeric benchmark, pricing, adoption, legal, and market claims in the pasted research are not implementation requirements and are not repeated as verified facts. Capability maturity is based on observed checks in this repository.

DeepInfer adds an inference compute substrate through `agi-coder-inference`. Model capability resides in the selected weights and agent behavior, not in the inference engine alone. Its integration supplies unverified text proposals; verification, planning, and authorization remain separate responsibilities. Neither upstream production use nor local mock tests establish AGI or native deployment maturity for this repository.
