    Faculty checks

    Each file is recomputed here. A pass is that computation, not a human baseline from the DeepMind cognitive framework. The same files are written to observations/faculties.json and recomputed when the process opens. Perception reads a grid. Attention keeps the target cells. Learning applies a new pair. Memory compares a later recall. Reasoning checks that a conclusion follows. Problem solving requires both the selection and the conclusion. Generation, executive function, social cognition, and metacognition keep their own checks.

    Perception

    The reported grid must match the frame that was parsed. Values stay 0 to 9.

    Attention

    Selected cells must be every target, in row order, and no other cell.

    Learning

    The held-out pair must be absent from training. The rule is searched, not named.

    Memory

    delay_steps must be at least 1. The count is in the file. It does not survive a restart.

    Reasoning

    The conclusion must equal the program applied to the premise.

    Problem solving

    Both the attention selection and the reasoning conclusion have to pass.

    Generation

    No program name is trusted. The check searches identity, transpose, flip_horizontal, and flip_vertical.

    Executive function

    Stages must be a ready prefix of the planner. production and editor must stay false.

    Social cognition

    The public key must be a valid ed25519 key and must differ from this process. The claimed grid is recomputed.

    Metacognition

    Pass means the recorded verdict matches a fresh run, including a recorded failure that really fails.
