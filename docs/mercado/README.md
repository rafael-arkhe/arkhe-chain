# Oferta ao mercado

Data de abertura: 16/11/2026.

Este pacote é a estrutura comercial que o código ainda não tinha: uma frase, três versões dela, um deck em que cada slide aponta para evidência ou fica vazio, um piloto com borda e um filtro para conversa com fundo. Ele prepara a primeira conversa com um comprador.

Não torna o Arkhe uma empresa em escala. Preço, lista de clientes, receita, TAM/SAM/SOM e pedido de capital estão em branco de propósito. O [registro de claims de 21/10/2026](../planning/2026-10-21-consolidated/CLAIMS-AND-DECISIONS.md) exclui percentual de mercado, previsão de receita, exclusividade e dever fiduciário. O [checklist de produção de 24/10/2026](../PRODUCTION-READINESS-2026-10-24.md) registra build e testes locais e recusa ler isso como produção qualificada.

A superfície que se mostra é o Intra: assinatura Ed25519, trilha, ancoragem Rekor quando configurada, exportação e verificação offline. O assistente local propõe. Assinatura, admissão e política continuam separados. Roteiro em [apps/arkhe-intra/README.md](../../apps/arkhe-intra/README.md).

Atualize a célula de evidência quando um teste, uma tela ou uma conversa datada passar a sustentar a frase. Conversa que a demo não responde tira a frase da oferta ou vira trabalho com teste. Não promove preprint a produto. Leitura de preço alheio e de sentença fica na seção de 17/11/2026 do deck; não preenche mercado, receita nem capital.
