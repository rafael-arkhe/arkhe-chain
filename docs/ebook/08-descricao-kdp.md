## Amostra atual — texto compatível com o conteúdo existente

**When an AI agent says an action is safe to approve, what can your system actually verify?**

This sample chapter from *Arkhe: Evidence and Governance for AI Agents* walks through a working code example that checks an arithmetic certificate before requesting authorization. Follow a proposal from input and output digests through a work record, a policy binding, an independent checker, and the ContainmentGate.

You will learn how to run the example, interpret its output, and examine rejection tests for missing evidence, changed requests, overflow, and policy denial. The chapter also explains why authorization does not establish execution, why retries require a journal, and why an offline inclusion proof needs a trusted checkpoint.

Written for platform engineers and software architects, this practical introduction makes each trust boundary explicit. The example uses synthetic inputs and performs no external action. Its certificate proves a bounded arithmetic property; it does not establish factual accuracy or general model correctness.

## Livro completo — rascunho para uso após a conclusão

**How do you turn an AI agent's proposal into an authorization your team can audit?**

*Arkhe: Evidence and Governance for AI Agents* is a practical implementation guide for platform engineers, software architects, and security professionals building systems in which agents can request consequential actions.

Follow the path from work intents and execution records to evidence admission, policy checks, and controlled execution. Explore canonical identities, independent certificate checking, offline inclusion proofs, and the operational responsibilities of journals and executors.

Executable examples and rejection cases explain both what each check establishes and which assumptions remain with the host. Discussions of governance, cost accounting, code agents, decentralized infrastructure, and content provenance distinguish implemented capabilities from experimental integrations.

This book helps you ask precise questions about evidence: who produced it, what it binds, which rule was checked, and what still requires trust. It provides an engineering method for evaluating agent workflows without promising general model correctness or automatic regulatory compliance.
