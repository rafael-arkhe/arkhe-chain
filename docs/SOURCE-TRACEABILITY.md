# Source Traceability

This environment derives from the supplied Arkhe draft and the reviewed
Arkhe Work Environment baseline.

Source-derived architectural commitments:
- cognition is replaceable and non-authoritative;
- WorkerExecutionRecord is the cognition/kernel boundary;
- containment is fail-closed;
- cognition never writes directly to WormGraph;
- cognition never holds signing authority;
- memory preserves trajectory;
- learning proposals require evidence and rollback;
- the company is intended as client zero;
- Work Environment is the defensible product term; AGI remains an empirical claim.

This repository materializes those contracts as a reference environment. It does
not silently upgrade design claims to empirical proof.
